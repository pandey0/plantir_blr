# Bangalore City Intel - Tactical Visual Schema

## Color Palette
- **Map Background**: Standard OSM (Natural) or CartoDB Dark (Tactical)
- **Ward Boundaries**: #00F2FF (Neon Cyan) | Stroke: 2px | Opacity: 0.8
- **Metro Purple**: #A020F0 (Vivid Purple) | Weight: 5px
- **Metro Green**: #00FF00 (Neon Green) | Weight: 5px
- **Active Signals**: #FF0055 (Crimson)
- **Archived Data**: #FF9D00 (Amber)

## Typography
- **Primary**: Inter / Sans-Serif
- **Weight**: 900 (Black) for Headers, 600 (Semibold) for UI labels
- **Effects**: Text-shadow for readability over map layers
